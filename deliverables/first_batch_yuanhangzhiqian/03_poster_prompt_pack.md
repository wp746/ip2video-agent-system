# 第一批节点海报提示词包

主题包：《远航之前》  
用途：微博配图 / 公众号头图 / 视频封面 / 朋友圈转发  
数量：3 组节点海报  
统一 IP：中国交建工程守护者双角色

## 通用视觉锁定

每张海报必须保留：

- 白色安全帽
- 安全帽正面中国交建标识
- 安全帽两侧蓝色横线
- 中国交建蓝色工装
- 胸口中国交建标识
- Q 版大眼工程 IP
- 男孩短发挥手形象
- 女孩双马尾形象
- 棕色工靴

统一风格：

电影感 3D IP 海报，真实港口、航运、桥梁、项目现场环境。中国交建蓝、工程白、海天蓝、港口暖金光、设备金属灰。画面克制、专业、温暖，不低幼，不娱乐化。

统一负面约束：

不要改变中国交建 logo 和蓝白品牌识别；不要出现不规范海上作业、危险施工动作或错误设备操作；不要让节日符号压过行业场景；不要做通用节日模板换皮；不要生成小而密的中文文字；预留标题区和品牌署名区。

## 1. 世界海员日海报

主标题方向：

**把平安写进每一段航程**

副标题方向：

远航之前，每一次确认都有意义。

微博配文：

远航不是从汽笛响起那一刻开始。  
在海图亮起之前，在对讲确认之前，在检查表最后一个勾画下之前，一线岗位已经把平安确认了一遍。  
世界海员日，致敬每一段被认真守护的航程。

画面创意：

驾驶舱与甲板结合。女孩 IP 在驾驶舱看海图、拿对讲机，男孩 IP 在甲板边拿安全检查表挥手确认。远处船舶驶向海平线，蓝色航线从海图延伸到海面。

### 竖版海报提示词 9:16

平面宣传海报，比例 9:16，主题：世界海员日。中国交建工程守护者双角色，必须保留白色中国交建安全帽、蓝色工装、胸口标识、Q版大眼、棕色工靴。场景为清晨驾驶舱与船舶甲板融合画面：女孩 IP 在驾驶舱看海图并拿对讲机，男孩 IP 在甲板安全线后拿安全检查表挥手确认。海图上的蓝色航线延伸到远处船舶和海平线。画面体现海员、远航、平安、坚守、四海为家。电影感 3D，真实港口航运环境，中国交建蓝、工程白、海天蓝、港口暖金光。构图上方预留大标题区“把平安写进每一段航程”，底部预留品牌署名区，不让模型生成小字。专业、温暖、可信，不低幼，不娱乐化。

### 横版海报提示词 16:9

平面宣传海报，比例 16:9，主题：世界海员日。左侧为驾驶舱海图近景，蓝色航线亮起；右侧为船舶甲板和海平线，男孩 IP 挥手确认，女孩 IP 通过对讲机复核。中国交建工程守护者双角色身份锚点必须清晰：白色安全帽、中国交建标识、蓝色工装、胸口标识。远处船舶驶向海平线，港口晨光温暖克制。标题区放在左上或中上，品牌署名区放右下。不要生成小字，不要改变 logo，不要危险作业。

## 2. 中国航海日海报

主标题方向：

**向海图强，一线守护看得见**

副标题方向：

数智赋能，领航未来。一条蓝线，连接港口、航程与远方。

微博配文：

一条航线通向海，也通向更远的通达。  
从港口到船舶，从图纸到航程，每一次抵达背后，都有一线岗位把责任落到动作里。  
中国航海日，跟着中国交建工程守护者，看见“数智赋能，领航未来”的每一步。

画面创意：

蓝色航线图成为主视觉，航线连接港口、桥梁、船舶、灯塔和海平线。双 IP 站在航线图前，一个指向远方，一个拿图纸确认。

### 竖版海报提示词 9:16

平面宣传海报，比例 9:16，主题：中国航海日。中国交建工程守护者双角色站在一张发光蓝色航线图前，航线从港口出发，连接船舶、桥梁、灯塔和海平线。女孩 IP 手持图纸和对讲机，男孩 IP 指向远方海面。必须保留白色中国交建安全帽、蓝色工装、胸口标识、Q版大眼、棕色工靴。画面体现数智赋能、领航未来、向海图强、交通强国、港航工程、四海通达。蓝色航线可带有克制的数据光点，但不能做成纯科幻宇宙风。电影感 3D，真实基础设施和航运环境。上方预留标题区“向海图强，一线守护看得见”，副标题区可后期加入“数智赋能，领航未来”，底部预留品牌署名区。不要做科幻宇宙风，不能脱离港口和工程场景。

### 方图海报提示词 1:1

平面宣传海报，比例 1:1，主题：中国航海日。中央是一条发光的中国交建蓝航线，像丝带一样连接港口、船舶、桥梁和海平线。双 IP 在前景，女孩 IP 看图纸，男孩 IP 举手确认方向。色彩为中国交建蓝、工程白、海天蓝、港口暖金光。构图干净，适合微博配图和公众号头图裁切。预留中文标题区和品牌署名区，不生成小字。

## 3. 安全生产月海报

主标题方向：

**把安全写进每一次确认**

副标题方向：

风险排查在前，平安抵达在后。

微博配文：

安全不是写在墙上的一句话。  
它写在检查表上，写在对讲机确认里，也写在一线岗位一次次重复的规范动作里。  
安全生产月，跟着中国交建工程守护者，把风险排查在前，把平安守在路上。

画面创意：

安全检查表作为核心道具。男孩 IP 在设备前勾选检查项，女孩 IP 通过对讲机确认；背景为港口设备、甲板、安全线和工程现场。

### 竖版海报提示词 9:16

平面宣传海报，比例 9:16，主题：安全生产月。中国交建工程守护者双角色在港口设备区完成安全确认，男孩 IP 手持安全检查表勾选项目，女孩 IP 拿对讲机复核信息。背景有港口机械、甲板安全线、设备提示灯、清晨工程现场。必须保留白色中国交建安全帽、蓝色工装、胸口标识、Q版大眼、棕色工靴。画面体现安全规范、风险排查、责任守护。中国交建蓝和工程白为主色，设备金属灰和港口暖金光辅助。预留大标题区“把安全写进每一次确认”和品牌署名区。不出现危险操作，不出现错误设备操作。

### 横版海报提示词 16:9

平面宣传海报，比例 16:9，主题：安全生产月。前景为安全检查表特写，最后一项被勾选，蓝色线条从检查表延伸到后方港口设备、甲板和船舶。双 IP 分工协作：男孩 IP 检查设备，女孩 IP 用对讲机确认。画面专业、克制、有工程现场可信度。标题区在左侧或上方，品牌署名区在右下。不要低幼化，不要通用安全海报模板，不要生成细小中文。

## 4. 视频封面版统一提示词

如需把三组海报改成视频封面，使用以下补充约束：

封面图需要更强的中心记忆点，主体更大，文字区更干净。IP 双角色占画面 35%-45%，行业场景占 40%，标题留白占 15%-25%。不要复杂背景堆叠，不要让船舶、港机、桥梁抢掉 IP。标题文字由后期设计添加，画面只留空白区域。

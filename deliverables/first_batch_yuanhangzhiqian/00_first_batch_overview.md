# 第一批内容生产包：《远航之前》

版本：2026-06-26  
客户场景：中国交建下属单位宣发考核 / 官方号投稿  
内容组合：1 条 60 秒 AIGC IP 故事视频 + 1 篇公众号特别策划 + 3 组节点海报  
核心 IP：中国交建工程守护者双角色

## 1. 第一批为什么选《远航之前》

第一批不建议从“最宏大”的口号开始，而要从一个官方号容易判断、公众容易理解、画面容易生成的具体场景开始：

**远航之前，海员和工程一线要把平安确认一遍。**

这个主题有三个好处：

- 能承接甲方已有的世界海员日参考海报，不浪费现有素材。
- 能自然融入安全生产月、中国航海日、世界海员日三个重要节点。
- 能把 IP 的可爱感放在专业动作里，而不是做成通用节日吉祥物。

第一批传播主张：

**远航不是从出发那一刻开始，而是从每一次安全确认开始。**

## 2. 三条内容线

### 视频线

栏目：《蓝线任务》  
单集：《远航之前》  
规格：60 秒 AIGC IP 故事视频  
用途：视频号、抖音、微博视频、官方号转载投稿  
目标：让观众觉得“这是一个有故事、有行业、有转发点的 IP AIGC 短片”。

核心故事：

清晨港口，一条蓝色航线在海图上亮起。中国交建工程守护者双角色接到“远航前最后一次确认”的任务，一个看图纸和航线，一个拿对讲机和安全检查表。他们从驾驶舱到甲板、从安全表到港口设备完成三次确认。最后观众发现，开头那条蓝线连接的不只是船舶和远方，也连接着城市通达、一线坚守和每一次平安抵达。

### 公众号线

栏目：《蓝线特别策划》  
文章：《远航之前，他们把平安检查了一遍》  
用途：公众号首发 / 官方号投稿 / 视频配套长文  
目标：不写成活动稿，而写成“特别策划”：用一线动作解释行业价值。

文章核心：

从港口清晨的一个动作写起：检查表、对讲机、海图、挥手送航。这不是简单的节日致敬，而是把安全、航运、工程责任和中国交建的行业属性讲成公众能看懂的故事。

### 海报线

用途：微博配图、公众号头图、朋友圈转发、视频封面  
第一批 3 组：

1. 世界海员日：《把平安写进每一段航程》
2. 中国航海日：《向海图强，一线守护看得见》
3. 安全生产月：《把安全写进每一次确认》

## 3. 官方口径与事实边界

本批内容参考以下公开方向：

- IMO 2026 年 Day of the Seafarer 主题为 “Carrying world trade. Carrying the risks.”，可转译为“承载世界贸易，也承受海上风险”，因此内容不能只写祝福，要写风险、责任与安全确认。
- 2026 年中国航海日活动于 7 月 11 日前后开展，主题为“数智赋能，领航未来”。本批中国航海日海报可在“向海图强”的基础上，加入“数智赋能、领航未来”的年度主题表达。
- 2026 年全国安全生产月主题为“人人讲安全、个个会应急——排查整治风险隐患”，本批内容可转译为“一线确认、风险排查、规范护航”。

## 5. 验收标准

视频验收：

- 60 秒内有完整故事，不是镜头堆砌。
- 双 IP 都有明确分工。
- 必须出现海图、对讲机、安全检查表、甲板/驾驶舱、港口/船舶。
- 结尾有情绪反转：平安远航来自出发前的一次次确认。

公众号验收：

- 标题像特别策划，不像新闻通稿。
- 正文从画面和动作进入，不从口号进入。
- IP 出现自然，不硬插。
- 能解释“为什么这件小事代表行业价值”。

海报验收：

- 一眼能看出中国交建工程/航运语境。
- IP 身份锚点不能变：白色安全帽、中国交建标识、蓝色工装。
- 节日符号不能压过行业场景。
- 必须预留标题区和品牌署名区。

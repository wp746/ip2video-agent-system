# 60 秒 AIGC IP 故事视频：《远航之前》

栏目：《蓝线任务》  
单集标题：《远航之前》  
时长：60 秒  
比例建议：9:16 竖版优先，兼容 16:9 横版二次裁切  
用途：视频号 / 抖音 / 微博视频 / 官方号投稿  
参考素材：IP 原型图 + 世界海员日参考海报

## 1. 核心创意

**远航不是从船离港那一刻开始，而是从每一次安全确认开始。**

故事用两个中国交建工程守护者 IP 完成一次“远航前最后确认”的任务：海图亮起、对讲确认、检查表勾选、甲板巡查、船舶离港。最后观众发现，开头那条蓝色航线连接的不只是海上的远方，也连接着港口、城市和一线岗位的平安。

## 2. 角色设定

男孩 IP：

- 行动型工程守护者。
- 负责甲板巡查、设备确认、挥手送航。
- 动作关键词：奔赴、检查、举手确认、挥手。

女孩 IP：

- 判断型工程守护者。
- 负责海图、对讲机、安全检查表、航线确认。
- 动作关键词：看图、标注、对讲、勾选。

双角色关系：

- 一个向远方看，一个把当下守住。
- 一个负责“出发”，一个负责“确认”。

## 3. 视频口播 / 字幕文案

建议使用少量旁白 + 屏幕大字，不做全程解说。

旁白版：

> 一段远航，开始于哪里？  
> 不是汽笛响起的那一刻，  
> 而是海图亮起之前，  
> 对讲机确认之前，  
> 检查表最后一个勾画下之前。  
> 远方很远，平安很近。  
> 中国交建工程守护者，和一线一起，把平安写进每一段航程。

屏幕大字建议：

- 0-5s：远航之前
- 12-20s：每一次确认，都有意义
- 30-40s：从港口，到远方
- 50-56s：平安，是抵达的底气
- 56-60s：把平安写进每一段航程

## 5. Seedance 分段提示词

### 使用素材建议

- `@图片1`：IP 角色设定图，作为人物形象锁定。
- `@图片2`：世界海员日参考海报中驾驶舱/海图/对讲机方向，作为行业场景参考。
- `@图片3`：世界海员日参考海报中港口/船舶/归航方向，作为氛围参考。
- 若素材数量受限，优先上传 IP 角色图 + 1 张驾驶舱参考 + 1 张港口船舶参考。

### 总提示词

参考 @图片1 的中国交建工程守护者双角色形象，必须保持白色安全帽、中国交建标识、蓝色工装、胸口标识、Q版大眼、棕色工靴等身份锚点。参考 @图片2 的驾驶舱、海图、对讲机、安全检查表氛围，参考 @图片3 的港口、船舶、海平线和归航氛围。生成一条 60 秒 AIGC IP 故事视频，标题《远航之前》。整体为电影感 3D IP 短片，真实港口与航运工程环境，中国交建蓝、工程白、海天蓝、港口暖金光、设备金属灰。画面专业、温暖、可信，不低幼，不娱乐化，不展示危险或不规范作业。

0-5 秒：清晨港口，俯拍一张海图，海图上的蓝色航线突然亮起，远处能看到船舶、港机和海平线剪影。女孩 IP 低头发现航线亮起，男孩 IP 从画面边缘跑入。镜头从海图慢慢推近蓝线，再切到港口远景。屏幕大字预留：“远航之前”。

5-12 秒：驾驶舱或港口值守台，安全帽、对讲机、图纸、安全检查表整齐铺开。女孩 IP 拿起对讲机，男孩 IP 戴好安全帽，两人准备执行远航前确认任务。镜头中景推近，扫过道具，最后定格双 IP。

12-20 秒：甲板或港口设备区，轻微风浪，设备提示灯亮起，但画面安全规范。男孩 IP 按安全检查表确认设备状态，女孩 IP 通过对讲机复核。镜头跟随男孩 IP 移动，穿插设备微距和检查表勾选特写。强调规范动作，不出现危险操作。

20-30 秒：双 IP 分工协作。女孩 IP 在海图上标注航线，男孩 IP 在甲板巡查。蓝色航线从海图中延伸到现实港口地面，形成创意转场。镜头从海图线条转为地面蓝线，连接两个角色的动作。

30-40 秒：镜头从 IP 手中的安全检查表推向港机、桥梁、船舶和海平线。检查表最后一项被勾选，港口设备开始有序运转。大范围拉远，展示中国交建工程与航运场景。画面宏大但不空，必须有具体岗位动作支撑。

40-50 秒：船舶准备离港，双 IP 和一线岗位人员站在安全线后挥手送航。男孩 IP 举手确认，女孩 IP 对讲确认完成。低角度仰拍，让船舶、甲板、IP 和港口晨光同框。氛围温暖、庄重。

50-56 秒：开头的蓝色航线再次出现，观众发现它连接着港口、远航船舶、城市灯光和一线岗位。镜头从航线图转为城市与海面的组合俯视图，形成情绪反转：每一次抵达背后，都有人提前确认平安。

56-60 秒：中国交建蓝白识别、双 IP、港口晨光形成稳定英雄收束画面。预留中文主题字幕和品牌署名区。屏幕大字建议：“把平安写进每一段航程”。结尾干净、稳重、适合官方号采用。

音效：港口环境声、远处船笛、对讲机轻响、纸张翻动、设备低鸣、海风。配乐为温暖克制的企业宣传片管弦氛围，逐步推进，不煽情过度。

负面约束：不要改变中国交建标识和蓝白品牌识别；不要出现不规范海上作业、危险施工动作或错误设备操作；不要把央企工程形象做成低幼娱乐化内容；不要生成小而密的中文文字；不要遮挡 IP 安全帽、胸口标识和蓝色工装；不要让节日符号压过行业场景。

## 6. 剪辑建议

# 官方号投稿与汇报材料：《远航之前》

用途：给甲方内部领导汇报 / 给中国交建官方号投稿 / 平台发布前整理

## 1. 项目一句话

用中国交建工程守护者 IP，讲一个“远航之前先把平安确认一遍”的 60 秒 AIGC 故事，配套公众号特别策划和三组节点海报，形成视频、图文、微博海报三线宣发包。

## 2. 领导汇报版话术

这次第一批内容不是单独做一张世界海员日海报，而是验证“IP 系列 AIGC 故事”的方向。

我们选择《远航之前》作为第一集，是因为它能同时承接世界海员日、中国航海日和安全生产月三个传播节点，也能把中国交建的港航工程、安全规范、一线岗位和蓝白品牌识别融合在一起。

内容上，我们用两个 IP 角色完成远航前最后一次确认：看海图、拿对讲、查设备、勾检查表、挥手送航。故事最后回收开头的蓝色航线，表达“每一次平安抵达，背后都有一线岗位提前确认”。

这个方向适合官方号采用，因为它不是单纯节日祝福，而是有故事、有行业、有岗位动作、有 IP 记忆点，也有后续全年系列化空间。

## 6. 内部审核清单

内容审核：

- 是否有明确一线岗位动作。
- 是否体现中国交建工程、航运、港口、安全属性。
- 是否避免通用节日模板。
- 是否没有未经核实的数据、项目成果或绝对化表述。

视觉审核：

- IP 形象是否与参考图一致。
- 中国交建标识是否清晰且未变形。
- 蓝白品牌识别是否稳定。
- 海图、对讲机、检查表、甲板/港口场景是否出现。

平台审核：

- 视频封面是否一眼能看懂。
- 公众号标题是否像特别策划。
- 微博配文是否适合转发。
- 海报是否预留标题区和署名区。

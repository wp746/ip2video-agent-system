## 2. 正文初稿

### 远航不是从汽笛响起那一刻开始

清晨的港口，天还没有完全亮。

驾驶舱里的海图先亮起一条蓝色航线。远处，船舶停在晨光里，港机的轮廓慢慢清晰，海风从甲板边缘吹过来。

如果把镜头拉远，这是一段即将开始的航程。

但如果把镜头推近，它其实从一张检查表开始。

安全帽有没有戴好，对讲机频道有没有确认，海图路线有没有复核，甲板设备有没有检查，提示灯有没有异常，最后一个勾有没有画下。

这些动作很小，小到不会出现在宏大的宣传语里。

可远方之所以能抵达，往往就藏在这些小动作里。

这一次，中国交建工程守护者接到的任务，就是在远航之前，把平安检查一遍。

### 一张海图亮起，一次任务开始

故事开始于一张海图。

蓝色航线从港口延伸到海平线，像一条被点亮的线。女孩工程守护者先发现了它。她拿起对讲机，低头看了一眼检查表；男孩工程守护者戴好安全帽，从值守台旁跑进画面。

他们没有说很多话。

一个看图，一个巡查。

一个确认航线，一个确认现场。

对他们来说，远航之前最重要的不是“出发”，而是“确认”。

确认不是一句口号，它有具体的声音：对讲机里短促的回应，纸张翻动的声音，检查表上笔尖落下的声音，设备运行时低低的嗡鸣。

这些声音组成了港口清晨最踏实的节奏。

### 每一次确认，都有意义

做节点宣传，最容易写成祝福。

世界海员日，祝远航平安；中国航海日，祝向海图强；安全生产月，讲安全责任。

这些话都对，但还不够。

真正能让人记住的，往往不是一句完整的口号，而是一个可以看见的动作。

比如，远航前的最后一次设备确认。

男孩工程守护者沿着甲板走过去，停在设备旁，按检查表一项一项确认。女孩工程守护者在驾驶舱里看着海图，通过对讲机复核信息。

画面里没有夸张的危险，也没有为了吸引眼球而制造的惊险。

只有规范、耐心、重复。

工程现场里的很多价值，正是在这样的重复里建立起来的。

重复确认，才能少一点风险。

按流程来，才能多一分底气。

### 从一张检查表，到一段航程

当检查表最后一项被勾选，镜头从纸面慢慢拉远。

观众会看到，刚才那条蓝色航线不只停留在海图上。它穿过港口，连接船舶，也连接远处的桥梁、道路和城市灯光。

这就是中国交建这类工程与航运内容最适合被 IP 化表达的地方。

宏大的词可以放在远景里，但故事一定要从近处开始。

从一个安全帽开始。

从一张图纸开始。

从一部对讲机开始。

从一张检查表开始。

当中国交建工程守护者把这些小物件拿起来，观众才会知道：这不是一张通用节日图，也不是一个随便换皮的 IP 短片。

这是发生在港口、船舶和工程现场里的故事。

### IP 的可爱感，要服务专业感

IP 形象天然有亲和力。

它能让严肃的行业内容更容易被公众接近，也能让复杂的工程场景更容易被看懂。

但在中国交建这样的传播语境里，IP 不能只是“可爱”。

它要有岗位动作。

它要遵守安全规范。

它要站在真实的港口、桥梁、甲板和项目现场里。

它要让观众一眼看出蓝白工装、安全帽标识、对讲机、图纸和工程设备之间的关系。

也就是说，IP 不是把行业内容变浅，而是把行业内容变得可感知。

观众不一定熟悉港航工程的完整流程，但他能看懂一个动作：远航之前，先把平安确认好。

### 平安，是抵达的底气

船舶准备离港时，天已经亮了。

男孩工程守护者站在安全线后举手确认，女孩工程守护者通过对讲机完成最后一次复核。

远处的船舶缓缓驶向海平线。

开头那条蓝色航线再次出现。

这一次，它不只是一条线。

它连接着海上的远方，也连接着港口的灯光；连接着城市的通达，也连接着一线岗位的坚守。

很多时候，我们看见的是抵达。

但抵达之前，还有很多人、很多动作、很多次确认，默默把平安放在前面。

远方很远，平安很近。

远航之前，他们把平安检查了一遍。

### 结尾建议

这个世界海员日 / 中国航海日 / 安全生产月，让我们把镜头交给一线。

看见远航之前的每一次确认，  
看见平安背后的每一个岗位，  
看见中国交建蓝，如何出现在每一次通达之前。

**中国交建工程守护者，把平安写进每一段航程。**

## 4. 审核重点

- 不要写成“祝大家节日快乐”的普通节日稿。
- 不要把 IP 写成卖萌角色。
- 不要出现具体未经核实的项目成果或数据。
- 所有动作都必须是规范、安全、正向的岗位动作。
- 中国交建标识和蓝白识别必须稳定。

# 需要甲方补充的资料清单

用途：让创意从“好看的概念”落到“真实工程节点”，避免视频、公众号、海报与项目实际脱节。

## 1. 最重要：项目节点台账

请甲方优先提供 3-5 个近期最值得宣传的项目，每个项目按下面格式给信息即可。

| 信息项 | 说明 | 示例 |
| --- | --- | --- |
| 项目名称 | 可公开名称或内部暂用名 | XX 大桥、XX 高速、XX 市政道路 |
| 项目类型 | 桥梁 / 高速 / 市政 / 轨道 / 房建 / 水利 / 隧道 | 特大桥 |
| 所在区域 | 省市、片区、湾区、城市群 | 广东中山、粤港澳大湾区 |
| 当前阶段 | 设计、开工、桩基、下构、架梁、合龙、桥面铺装、交工、通车 | 主桥合龙前 |
| 近期节点 | 未来 1-3 个月可宣传节点 | 首桩、首墩、首片梁、首节段、合龙、贯通、通车 |
| 节点时间 | 大概月份即可 | 2026 年 8 月 |
| 节点意义 | 为什么值得说 | 控制性工程、关键工序、阶段突破 |
| 可公开程度 | 项目名/数据/画面是否可公开 | 可公开项目名，不公开具体造价 |

没有这个台账，A/B 两条宏观创意容易停留在“桥很美”“精度很重要”，但无法打到工程真实发生的那一刻。

## 2. 项目亮点与难点

每个项目最好补 3 类信息：

- 工程难点：跨江、跨线、深水、软基、高墩、大跨、复杂交通导改、工期紧等。
- 技术亮点：工法、装备、数字化、BIM、智慧梁场、智能监测、绿色施工等。
- 管理亮点：安全、质量、进度、标准化、党建联建、劳动竞赛、青年突击队等。

这些信息会决定创意到底是走：

- “一桥连万家”的民生通达线；
- “超级工程的一厘米”的精度技术线；
- 还是“公司历史/桥品牌”的品牌传承线。

## 3. 可公开素材

请甲方尽量提供：

- 项目现场照片：桥梁、道路、梁场、钢筋、桩基、桥墩、架梁、铺装、夜间施工等。
- 航拍或视频素材：如可提供 5-15 秒短视频更好。
- 典型人物照片：项目经理、测量员、安全员、质检员、青年员工，若不能露脸也可以只给背影/动作。
- 工具道具照片：图纸、安全帽、对讲机、测量仪、检查表、反光背心、塔尺、全站仪等。
- 企业视觉规范：logo、标准色、署名规范、结尾口号。

## 4. 传播边界

需要甲方确认：

- 是否可以出现具体项目名？
- 是否可以出现具体数据，如桥长、跨径、桩基数量、通车日期？
- 是否可以出现公司历史节点，如 1963、221 工程 750 道路、1982 南下、1986 落户中山？
- 是否可以出现下属单位全称？
- 是否需要同时露出中国交建、中交路建、中交路桥华南的层级关系？
- 哪些画面不能出现：未完工结构、施工细节、人员正脸、项目位置、设备型号等。

## 5. 官方号偏好

如果甲方知道上级官方号偏好，请补充：

- 近期官方号喜欢什么类型：故事类、人物类、节点类、技术类、节日类？
- 有没有被采纳过的优秀案例？
- 视频一般喜欢多长：30 秒、60 秒、90 秒？
- 公众号喜欢“特别策划”还是“项目新闻改写”？
- 海报是否需要固定尺寸或固定落款？

## 6. 最小资料包

如果甲方来不及整理，至少给这 5 样：

1. 近期 3 个重点项目名称和节点。
2. 每个项目 5 张现场图。
3. 每个项目一句话亮点。
4. 哪些数据可公开、哪些不能公开。
5. 公司 logo / IP 原型 / 落款规范。

有了最小资料包，我们就能把三个创意方向从“概念提案”推进到“可生产脚本”。

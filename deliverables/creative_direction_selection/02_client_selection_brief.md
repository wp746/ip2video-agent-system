# 给甲方选择的三条创意方向简版

这次我们不直接进入制作，而是先提供 3 条创意方向供甲方选择。甲方选定后，我们再按选中的方向展开 60 秒 AIGC 视频、公众号特别策划和节点海报。

## 方向 A：一桥连万家

类型：宏观传播方向  
关键词：桥梁、城市、万家灯火、生活通达  
一句话：一座桥不只是跨过江河，也跨过城市、生活和每个人回家的路。

适合：

- 做公众传播。
- 做节日节点。
- 做官方号更容易转发的温暖主题。

视频感觉：

IP 跟随一条亮起的桥线，从清晨车流到夜晚灯火，看到桥如何连接上班、上学、物流、团圆和城市生活。

适合标题：

- 一桥连万家
- 一座桥的终点，是万家灯火
- 桥通向哪里？通向每个人的生活

## 方向 B：超级工程的一厘米

类型：宏观创意方向  
关键词：超级工程、精度、质量、安全、技术  
一句话：宏大的桥梁，往往从一厘米的精度开始。

适合：

- 做更有 AIGC 视觉冲击力的视频。
- 做质量月、安全生产月、科技创新、工法专利相关传播。
- 展示公司专业能力和工程细节。

视频感觉：

IP 进入“工程细节世界”，钢筋像森林、螺栓像塔、测量线像蓝色光轨。最后镜头拉远，观众发现这一厘米托起的是一座完整大桥。

适合标题：

- 超级工程的一厘米
- 一座大桥，为什么要从一厘米讲起？
- 看不见的精度，撑起看得见的通达

## 方向 C：一张图纸走了六十年

类型：公司专属方向  
关键词：1963、三线建设、南下广东、中山、桥品牌、特大桥  
一句话：从三线建设到湾区通达，一张图纸走过六十年，走成了今天的桥与路。

适合：

- 做公司品牌特别策划。
- 做领导汇报。
- 做最能体现中交路桥华南独特性的第一条内容。
- 做官方号“有故事、有历史、有精神”的投稿。

视频感觉：

IP 在档案室发现一张泛黄老图纸。蓝色线条从图纸上亮起，带着 IP 穿过 1963、南下广东、中山落地、桥品牌形成和新时代工程现场。最后老图纸与现代数字图纸重叠，变成一座通向远方的大桥。

适合标题：

- 一张图纸走了六十年
- 从 750 道路到 110 余座特大桥
- 为什么说一座桥，藏着一家公司的来路？

## 我们的建议

如果甲方希望第一批内容最能代表自己，建议优先选：

**方向 C：一张图纸走了六十年**

原因：

- 这是中交路桥华南自己的故事，不是通用央企工程模板。
- 能把公司历史、桥品牌、华南区域和建设者精神串起来。
- 适合做 60 秒 AIGC IP 故事，也能自然延展成公众号和海报。

如果甲方更想先做公众传播，可以选 A。  
如果甲方更想做视觉创意和专业技术感，可以选 B。

## 甲方只需要确认

1. 三条方向中优先选哪一条？
2. 如果选 C，是否允许使用“1963”“221 工程 750 道路”“1982 南下”“1986 落户中山”等历史节点？
3. 是否需要露出具体项目、桥梁名称或公司内部口号？

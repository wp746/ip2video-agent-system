# 给甲方选择的三条创意方向简版

这次我们不直接进入制作，而是先提供 3 条创意方向供甲方选择。甲方选定后，我们再按选中的方向展开 60 秒 AIGC 视频、公众号特别策划和节点海报。

## 方向 A：一桥连万家

类型：宏观传播方向  
关键词：通车、合龙、交工、桥面铺装、城市通达  
一句话：这不是一座桥完成的那一刻，而是城市重新靠近的那一刻。

适合：

- 有近期通车、交工、合龙、桥面铺装、交通转换节点。
- 做公众传播和官方号转发。
- 做国庆、中秋、春节返乡等生活通达节点。

视频感觉：

IP 跟随“通车前的最后一条线”：最后一条标线划下、最后一遍桥面检查完成、第一辆车驶过。桥线一路延伸到学校、医院、市场、工厂和万家灯火。

适合标题：

- 一桥连万家
- 通车前的最后一条线
- 一座桥通车，很多人的生活就近了一步

## 方向 B：超级工程的一厘米

类型：宏观创意方向  
关键词：首桩、首墩、首片梁、首件验收、质量、安全、精度  
一句话：超级工程不是从宏大镜头开始，而是从第一处被确认的精度开始。

适合：

- 有近期首桩、首墩、首片梁、首件验收、架梁、质量月、安全生产月节点。
- 做更有 AIGC 视觉冲击力的视频。
- 展示公司专业能力、质量管理和工程细节。

视频感觉：

IP 进入“首件之前的一厘米”。女孩 IP 复核图纸尺寸，男孩 IP 跟着测量员、质检员、安全员完成三次确认。最后镜头拉远，观众发现这一厘米托起的是第一片梁、第一座墩或一座完整大桥。

适合标题：

- 超级工程的一厘米
- 首件之前的一厘米
- 一座大桥的第一步，藏在一次复核里

## 方向 C：一张图纸走了六十年

类型：公司专属方向  
关键词：1963、三线建设、南下广东、中山、桥品牌、特大桥  
一句话：从三线建设到湾区通达，一张图纸走过六十年，走成了今天的桥与路。

适合：

- 做公司品牌特别策划。
- 做领导汇报。
- 做最能体现中交路桥华南独特性的第一条内容。
- 做官方号“有故事、有历史、有精神”的投稿。

视频感觉：

IP 在档案室发现一张泛黄老图纸。蓝色线条从图纸上亮起，带着 IP 穿过 1963、南下广东、中山落地、桥品牌形成和新时代工程现场。最后老图纸与现代数字图纸重叠，变成一座通向远方的大桥。

适合标题：

- 一张图纸走了六十年
- 从 750 道路到 110 余座特大桥
- 为什么说一座桥，藏着一家公司的来路？

## 我们的建议

如果甲方暂时没有整理好具体项目节点，建议优先选：

**方向 C：一张图纸走了六十年**

原因：

- 这是中交路桥华南自己的故事，不是通用央企工程模板。
- 能把公司历史、桥品牌、华南区域和建设者精神串起来。
- 适合做 60 秒 AIGC IP 故事，也能自然延展成公众号和海报。

如果甲方有近期通车、合龙、交工节点，可以选 A。  
如果甲方有近期首件、首桩、首片梁、质量安全节点，可以选 B。

## 甲方只需要确认

1. 三条方向中优先选哪一条？
2. 最近 1-3 个月有没有明确项目节点：首桩、首墩、首片梁、合龙、通车、交工、质量月、安全生产月？
3. 是否允许露出具体项目名、节点时间、现场画面和关键数据？
4. 如果选 C，是否允许使用“1963”“221 工程 750 道路”“1982 南下”“1986 落户中山”等历史节点？

# 中交路桥华南 IP 系列 AIGC 第一轮创意方向提案

目的：每次进入正式生产前，先给甲方 3 条创意方向选择。甲方选中后，再展开 60 秒 AIGC 视频、公众号特别策划、海报与投稿包。

适用对象：中交路桥华南工程有限公司  
核心 IP：中国交建工程守护者双角色  
创意边界：不再以海员、远航、港口作为主线；重点转向路桥、特大桥、市政、轨道、城市通达、工程精度、建设者精神。

## 方向总览

> 2026-06-27 纠偏：A、B 两个宏观方向的原版更像传播母题，创意成立但不够贴工程实际节点。正式给甲方选择和后续实施时，优先使用 `04_node_driven_creative_directions_v2.md` 中的节点驱动版：A 绑定通车/合龙/交工节点，B 绑定首桩/首件/质量安全节点。

| 编号 | 方向类型 | 创意名称 | 核心看点 | 更适合 |
| --- | --- | --- | --- | --- |
| A | 宏观方向 | 《一桥连万家》 | 把桥从工程变成人与城市的情感连接 | 官方号转发、公众传播、节日节点 |
| B | 宏观方向 | 《超级工程的一厘米》 | 用微观精度讲大国工程，画面有创意 | AIGC 视频出彩、科技质量安全传播 |
| C | 公司方向 | 《一张图纸走了六十年》 | 从 1963 到今天，讲中交路桥华南自己的历史 | 甲方领导汇报、公司品牌片、周年/专题 |

建议优先级：

- 如果甲方想先要“最容易被公众转发”：选 A。
- 如果甲方想先要“最有 AIGC 视觉创意”：选 B。
- 如果甲方想先要“最能体现公司独特性”：选 C。

我建议第一批正式生产优先选 **C《一张图纸走了六十年》**，因为它最贴甲方资料，也最能避免做成中国交建系统里的通用内容。A 和 B 可以作为后续系列分支。

## A. 宏观方向一：《一桥连万家》

### 1. 一句话

一座桥不只是跨过江河，也跨过城市、生活和每个人回家的路。

### 2. 创意逻辑

中国交建和中交路桥华南的行业属性，很适合讲“通达”。但“通达”如果只写成口号，会很空。这个方向把桥梁拍成公众能感知的生活连接：

- 上班的人过桥。
- 孩子坐车去学校。
- 货车把物资送进城市。
- 夜晚城市灯光从桥上延伸。
- IP 在桥上发现每个人都有自己的目的地。

桥是主角，但不是冷冰冰的工程物。桥连接的是人的生活。

### 3. 60 秒视频故事

片名：

**《一桥连万家》**

故事：

清晨，IP 在一张城市地图上看到一座桥的线条亮起。男孩 IP 以为任务是“找到这座桥的终点”，女孩 IP 发现桥上的每一个光点都代表一个人的目的地。镜头跟随桥上的车流、校车、货车、骑行者和夜归人。最后 IP 发现，桥的终点不是地图上的某个点，而是万家灯火。

记忆点：

开头是一条桥线亮起，结尾这条线变成城市灯火。

### 4. 公众号特别策划

标题建议：

- 一座桥的终点，是万家灯火
- 桥通向哪里？通向每个人的生活
- 从一座桥，看见城市如何靠近

文章角度：

从“桥的终点在哪里”这个问题切入，不堆工程数据，而写桥如何改变通勤、物流、城市空间和生活半径。IP 作为带路者，带公众从桥面走向桥背后的建设逻辑。

### 5. 海报方向

标题：

**一桥连万家**

画面：

桥梁横跨画面，白天车流与夜晚灯火在同一张图中融合。IP 站在桥面或桥头，手中拿着发光路线图。远处城市灯光被桥连接起来。

### 6. 适合节点

- 国庆节
- 春节返乡
- 中秋节
- 劳动节
- 重大项目通车节点

### 7. 风险

这个方向公众传播友好，但公司独特性不如 C 强，需要在画面和文案里加入“中交路桥华南桥品牌”“特大桥专业领航企业”等识别。

## B. 宏观方向二：《超级工程的一厘米》

### 1. 一句话

宏大的桥梁，往往从一厘米的精度开始。

### 2. 创意逻辑

工程传播最容易只拍“大”：大桥、大车、大机械、大场面。但真正体现专业性的，是小到毫米、厘米级的控制：测量点、焊缝、螺栓、钢筋间距、模板线、标高、检查表。

这个方向适合 AIGC，因为可以把 IP 缩小进入“工程细节世界”，把一厘米拍成一场冒险。

### 3. 60 秒视频故事

片名：

**《超级工程的一厘米》**

故事：

IP 在桥梁施工现场看到一个闪光的“一厘米”。他们被吸入图纸和结构细节的微观世界：钢筋像森林，螺栓像塔，测量线像蓝色光轨。男孩 IP 负责跑现场，女孩 IP 负责校准图纸。最后镜头拉远，观众发现这一厘米的确认，托起的是一座完整大桥。

记忆点：

从微观“一厘米”拉远到宏观“大桥”，视觉反差强，适合转发。

### 4. 公众号特别策划

标题建议：

- 一座大桥，为什么要从一厘米讲起？
- 超级工程里，最不能忽略的那一厘米
- 看不见的精度，撑起看得见的通达

文章角度：

不讲抽象质量管理，而讲工程里的“精度感”：测量、复核、巡检、工法、专利、创新。用 IP 把复杂技术变成公众能理解的画面。

### 5. 海报方向

标题：

**超级工程的一厘米**

画面：

前景是 IP 站在一把巨大的工程尺/测量线旁，蓝色刻度“一厘米”发光；背景是正在成型的桥梁结构。微观和宏观同框。

### 6. 适合节点

- 质量月
- 安全生产月
- 科技创新周
- 项目施工节点
- 工法/专利/鲁班奖相关传播

### 7. 风险

这个方向视觉最有创意，但需要甲方确认是否可以使用施工细节、测量、桥梁结构等专业画面，避免出现不准确工艺。

## C. 公司方向：《一张图纸走了六十年》

### 1. 一句话

从三线建设到湾区通达，一张图纸走过六十年，走成了今天的桥与路。

### 2. 为什么这是公司方向

这是最贴中交路桥华南资料的一条。

公司资料里最有辨识度的内容不是“我们会修桥”这么简单，而是：

- 1963 年成立。
- 伴随国防而生，为新中国第一颗原子弹爆炸修建 221 工程 750 道路。
- 1982 年南下投身改革开放，1986 年落户广东中山。
- 如今国内外已建、在建特大型桥梁 110 余座。
- “桥品牌”成为国内知名品牌。
- 2022-2024 连续 3 年获评中交集团 TOP20 三级工程公司。

这些内容很适合做成一条“时间线故事”，也最能体现“这是中交路桥华南自己的故事”，不是中国交建系统里任何一家单位都能套用。

### 3. 60 秒视频故事

片名：

**《一张图纸走了六十年》**

故事：

中国交建工程守护者在档案室里发现一张泛黄的老图纸。图纸上写着“750 道路”。当女孩 IP 轻轻展开图纸，蓝色线条从纸上亮起，把两个 IP 带回 1963 年的三线建设现场。随后线条继续向南延伸，经过改革开放、广东中山、湾区城市、特大型桥梁和新时代工程现场。最后，老图纸与今天的数字图纸重叠，变成一座通向远方的大桥。

结尾字幕：

**固基修道，履方致远。**

记忆点：

一张老图纸，从纸面走到今天的桥面。

### 4. 8 段式 60 秒结构

| 时间 | 内容 | 画面 |
| --- | --- | --- |
| 0-5s | 档案室钩子 | IP 发现一张泛黄图纸，蓝色线条亮起 |
| 5-12s | 1963 起点 | 图纸把 IP 带到三线建设道路现场 |
| 12-20s | 南下广东 | 蓝线一路向南，出现广东、中山、改革开放氛围 |
| 20-30s | 桥品牌形成 | 桥梁结构、架梁、桥墩、测量动作快速展开 |
| 30-40s | 超级工程 | 特大型桥梁、道路、市政、轨道、城市通达场景 |
| 40-50s | 技术与荣誉 | 工法、专利、鲁班奖/詹天佑奖以抽象光标呈现，不堆小字 |
| 50-56s | 反转 | 老图纸与现代数字图纸重叠，变成今天的一座桥 |
| 56-60s | 品牌收束 | IP 站在桥头，字幕“固基修道，履方致远” |

### 5. 公众号特别策划

标题建议：

- 一张图纸，走过了中交路桥华南的六十年
- 从 750 道路到 110 余座特大桥
- 为什么说一座桥，藏着一家公司的来路？

文章角度：

这篇不写普通新闻稿，而写“公司精神的来路”：从三线建设的路，到改革开放南下，再到今天的桥品牌。IP 作为“打开档案的人”，把历史转译成画面和故事。

### 6. 海报方向

标题：

**一张图纸走了六十年**

副标题：

固基修道，履方致远。

画面：

一张泛黄老图纸和一张现代数字工程图纸上下叠合，中间是一条中国交建蓝线。蓝线从老道路延伸到现代特大桥和城市灯火。IP 双角色站在图纸边缘，一个托起老图纸，一个指向远方桥梁。

### 7. 适合节点

- 公司周年
- 品牌宣传月
- 重大项目节点
- 领导汇报
- 官方号“特别策划”
- 企业文化专题

### 8. 风险

需要甲方确认：

- 是否允许在视频/文章中提及 221 工程 750 道路。
- 是否可以使用“1963”“1982”“1986”等历史节点。
- 是否有内部更标准的公司历史表述。

如果甲方担心历史表述敏感，可以弱化为：

“从一张老图纸开始，公司把一代代建设者的脚步，铺成今天通向城市的桥与路。”

## 选择建议

### 推荐甲方选择方式

给甲方时不要问“喜欢哪个”，而是问：

1. 这次是更想先被公众转发，还是更想体现公司独特性？
2. 这次是否可以讲公司历史？
3. 是否希望第一条视频更像“品牌片”，还是更像“爆款创意短片”？

### 我的推荐

第一批正式实施建议选：

**C《一张图纸走了六十年》**

原因：

- 这是甲方自己资料里最有辨识度的故事。
- 能把 1963、三线建设、南下广东、桥品牌、特大桥 110 余座串成一条线。
- 有足够情绪，也有足够行业属性。
- 能自然转成视频、公众号、海报三种内容。
- 不会落入“通用央企工程 IP 模板”。

第二优先级：

**B《超级工程的一厘米》**

原因：

- AIGC 画面最有想象力。
- 适合后续做质量、安全、科技创新方向。

第三优先级：

**A《一桥连万家》**

原因：

- 传播最亲民。
- 适合节日节点、国庆、中秋、春节等公众情绪节点。

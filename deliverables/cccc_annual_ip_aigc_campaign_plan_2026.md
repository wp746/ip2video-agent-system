# 中国交建下属单位 IP 系列 AIGC 宣发年度策划全案

版本：2026-06-26  
周期：2026 年 7 月 - 2027 年 6 月滚动全年  
适用：视频号 / 抖音 / 微博 / 公众号 / 官方号投稿与宣发考核  
核心资产：中国交建工程守护者 IP 双角色

## 一、汇报用结论

甲方这次不应只做单张节日海报或单条短视频，而应做成一个可持续投稿的 IP 系列 AIGC 内容工程。

建议全年总主题定为：

**《蓝线任务：跟着中国交建工程守护者去一线》**

一句话阐释：

> 用两个中国交建工程 IP，把宏大的港航、桥梁、基建、安全和交通强国叙事，讲成一分钟能看懂、愿意转发、官方号容易采用的一线故事。

年度传播主张：

- 视频做“系列故事”，每月 1 条 60 秒 AIGC IP 故事。
- 公众号做“特别策划”，每月 1 篇图文，承接视频故事背后的行业价值。
- 海报做“节点传播”，每月 2-4 张节日/行业节点海报，适合微博配文和公众号头图。

领导可听懂的价值：

- 对上级官方号：提供成体系、成系列、可长期采用的内容，而不是零散素材。
- 对甲方考核：视频、公众号、微博海报三线并行，提高被不同平台采纳的概率。
- 对企业形象：把中国交建的专业、安全、责任和温度，用年轻化 IP 和 AIGC 方式讲出来。
- 对复用效率：全年节点可沉淀成模板，后续只换项目、节点、岗位动作即可继续生产。

## 二、调研判断

公开资料显示，中国交建/中交集团是全球领先的特大型基础设施和城市建设领域综合服务商，传播内容天然适合围绕“大交通、大城市、港航工程、桥梁道路、城市建设、国际工程、装备制造、安全生产”展开。

中国交建品牌文化文章提到，中交集团整合报纸、网站、微信、微博、抖音、快手等自有传统媒体和新媒体，建立传播矩阵，并围绕重大节点、重要事件制定全年媒体沟通计划。这说明甲方下属单位内容如果想被上级采用，不能只做单点创意，要主动对齐“重大节点 + 重要事件 + 全年媒体沟通计划”的节奏。

国资央企 AIGC 创意传播活动已经把“优秀 AIGC 视频作品”“AI+IP 形象应用案例”等作为明确类别。甲方强调官方喜欢 IP 系列 AIGC 故事，方向是成立的，但内容必须同时满足三点：故事性、行业性、正向传播价值。

## 三、全年内容架构

年度母题：

**蓝线任务**

“蓝线”有三层含义：

- 品牌蓝：中国交建蓝白视觉识别。
- 航线/路线：港口、桥梁、公路、城市通达。
- 安全线：一线岗位中的规范、责任和守护。

IP 角色设定：

- 男孩 IP：行动型工程守护者，负责巡检、挥手、奔赴、现场确认。
- 女孩 IP：智慧型工程守护者，负责图纸、航线、对讲、风险提示。
- 双角色关系：一个看见远方，一个守住当下；一个负责行动，一个负责判断。

每条内容都遵循同一公式：

**一个节点 + 一个一线岗位动作 + 一个工程场景 + 一个情绪反转 + 一个品牌收束**

## 四、视频方向：1 分钟 AIGC IP 系列故事

栏目名：

**《蓝线任务》**

定位：

每月一集 60 秒 AIGC IP 故事短片，面向视频号、抖音、微博视频和官方号转载。每集用一个节点或项目场景，让 IP 完成一个小任务，最后落到中国交建的行业价值。

单集结构：

| 时间 | 内容功能 | 画面要求 |
| --- | --- | --- |
| 0-5s | 强钩子 | 海图亮起、桥梁呼吸、港口灯火、设备预警等奇观开场 |
| 5-12s | IP 接任务 | 双角色进入现场，安全帽、对讲机、图纸等身份锚点出现 |
| 12-20s | 一线风险 | 风浪、暴雨、设备提醒、工期节点，但不制造危险违规动作 |
| 20-30s | 协作展开 | 男孩行动、女孩判断，体现岗位协作 |
| 30-40s | 大工程展开 | 从小动作推到桥梁、港口、船舶、城市通达 |
| 40-50s | 节点情绪 | 节日/行业节点出现，但服务故事，不喧宾夺主 |
| 50-56s | 记忆反转 | 开头线索回收，形成想转发的情绪点 |
| 56-60s | 品牌收束 | 中国交建蓝白识别 + 主题字幕 + 署名空间 |

视频风格要求：

- 不做纯科幻，不做低幼动画，不做硬广口播。
- 画面要有真实工程质感：港口晨光、桥梁结构、船舶甲板、施工现场、图纸纸张、金属设备。
- IP 可以可爱，但动作必须专业：巡检、确认、看图、对讲、挥手、守航、点亮。
- 结尾要适合官方号采纳：简短、庄重、有温度。

## 五、公众号方向：特别策划系列

栏目名：

**《蓝线特别策划》**

定位：

公众号不只是视频的文字版，而是把短视频背后的行业价值讲透。每篇文章采用“故事开场 + 一线动作 + 行业解释 + IP 配图 + 品牌收束”的方式，避免 AI 腔和空泛宣传。

文章结构：

1. 标题：像特别策划，不像活动通知。
2. 开头：从一个具体画面开始，比如“凌晨的港口灯光还亮着”。
3. 一线故事：让 IP 带出岗位动作。
4. 行业解释：讲这件小事为什么重要。
5. 图文配合：首图、正文插图、结尾卡片都围绕 IP 原型创作。
6. 收束：落到中国交建、下属单位和节点主题。

公众号标题风格示例：

- 不写：“世界海员日宣传稿”

- 不写：“致敬一线建设者”
- 改写：“一张图纸到一座桥，中间隔着多少次确认？”
- 不写：“中国交建 IP 宣传特别策划”
- 改写：“两个小小工程守护者，带你看懂一条蓝线”

## 六、海报方向：重点节点 IP 海报矩阵

定位：

海报主要服务微博、公众号头图、朋友圈转发、视频封面和官方号节点传播。海报不追求每张都复杂，而要稳定做到“节点准确 + 行业明显 + IP 好认 + 文案可转发”。

全年海报分三类：

- 行业节点海报：安全生产月、中国航海日、世界海员日、质量月。
- 全民节日海报：春节、元宵、端午、中秋、国庆、冬至。
- 社会情绪节点海报：妇女节、母亲节、父亲节、教师节、劳动节。

海报视觉规则：

- 必须出现 IP 身份锚点：白色中国交建安全帽、蓝色工装、胸口标识、棕色工靴。
- 必须出现行业场景：港口、桥梁、船舶、图纸、设备、项目现场、对讲机、安全检查表。
- 节日符号只能作为辅助：粽子、月亮、春联、花束、灯笼不能压过工程主体。
- 每张必须预留标题区和品牌署名区，不让模型生成小字。

重点节点海报创意池：

| 节点 | 海报标题方向 | 画面创意 |
| --- | --- | --- |
| 中国航海日 | 向海图强，一线守护看得见 | IP 展开航线图，蓝线连接港口、船舶、灯塔和海平线。 |

| 国庆节 | 通达山河，守护流动中国 | IP 站在桥梁、港口、城市天际线之间，画面庄重克制。 |
| 春节 | 有人归家，有人守航 | 港口灯光、春联、归航船舶和值守岗亭同框。 |
| 端午节 | 端午安康，平安守航 | 粽叶化成航线图，IP 在港口完成安全巡检。 |

微博配文模板：

## 八、首轮执行建议

首轮不要一次铺全年制作，建议先做“1+1+3”验证包：

- 1 条 60 秒 AIGC 故事视频：《远航之前》
- 1 篇公众号特别策划：《远航之前，他们把平安检查了一遍》
- 3 张微博/公众号海报：世界海员日、安全生产月、中国航海日方向

验证目标：

- 看官方号是否认可“IP 系列 AIGC 故事”的方向。
- 看视频故事是否比单张海报更容易被转发。
- 看公众号特别策划是否能承接视频背后的行业价值。
- 看海报风格是否足够中国交建、足够节点化、足够转发友好。

## 九、甲方汇报话术

可以这样向领导汇报：

> 我们不准备只做几张节日海报，而是围绕中国交建工程 IP，搭建一个全年可持续的 AIGC 宣发内容体系。视频端做一分钟 IP 系列故事，公众号端做特别策划，微博端做节点海报。每个内容都围绕一个真实的一线动作，把港航、桥梁、基建、安全生产等行业属性讲得更年轻、更有传播力，也更适合上级官方号采纳。

领导最关心的三点：

- 有系列：全年 12 个视频故事，不是一次性内容。
- 有行业：每条都落到港航、桥梁、项目、安全、通达，不做通用 IP。
- 有考核：视频、公众号、海报三线投稿，提高被官方号采纳概率。

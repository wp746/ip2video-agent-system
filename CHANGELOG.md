# Changelog

## 0.1.0

- Recreated the local IP2Video agent skeleton from reference screenshots.
- Added five deterministic production pipelines.
- Added scoring, validation, templates, universe config, and Markdown generation.
- Added a runnable Sprout Guardian example.

## 0.2.0

- Added input compiler, IP bible builder, compliance review, asset ledger, storyboard contract, prompt validator, and QA export pipelines.
- Added bundled exports: production manifest, asset ledger, shot contract, negative prompts, QA report, and direct Seedance prompt text files.
- Updated prompt generation to include reference-duty split and compliance constraints.
- Added production package validator script.

## 0.3.0

- Added reusable story archetype config for medical, children, brand, and suspense formats.
- Added visual specification contract config for asset-board panel requirements.
- Upgraded story generation to use template-specific beat grammar, purpose, and emotional curve.
- Upgraded visual generation to output prompt blocks and asset spec contracts.
- Added per-shot video prompts and exported `shot_prompts.yaml` / `shot_prompts.md`.
- Strengthened prompt validation for identity-anchor coverage and reference-duty coverage.

## 0.4.0

- Added pre-production research pipeline: research planner, design research, and research synthesis.
- Added `config/design_research_framework.yaml` for audience, category, visual, narrative, forbidden-tone, and reference-keyword strategy.
- Input compiler now merges research strategy and can adopt the research-recommended style template when the user does not specify one.
- Manifest and Markdown output now include design research and production strategy.

## 0.5.0

- Added multi-channel promotion pipelines: channel planner, campaign calendar, WeChat content, and poster design.
- Added China campaign/festival calendar with major public, lunar, social, and commerce nodes.
- Added WeChat article package generation with title options, editorial body draft, festival planning, and IP-based illustration prompts.
- Added poster prompt package generation for square, vertical, and mobile poster formats.
- Export bundle now includes channel plan, campaign calendar, WeChat content files, and poster prompt files.

## 0.6.0

- Added the `engineering_maritime` research profile for SOE infrastructure, port, shipping, safety, and official-account campaign scenarios.
- Added the `INF-A` template and infrastructure/maritime story archetype.
- Added the `CLIENT_CASE_PLAN` pipeline for client-facing full case plans, annual node strategy, channel architecture, and verification matrix.
- Upgraded campaign calendar adaptation so public festivals are translated into engineering/maritime communication angles when the profile requires it.
- Upgraded poster packages to include Weibo caption suggestions alongside headline directions and image-generation prompts.
- Added the China Communications Construction test input and engineering maritime universe config.

## 0.7.0

- Added 60-second IP story support for full AIGC video series campaigns.
- Added `seedance_2_5_60s.txt` to exported production bundles and validator checks.
- Added the `INF-A` 60-second eight-beat structure for engineering/maritime IP stories.
